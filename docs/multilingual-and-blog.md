# Три мови та блог

## Мови

- Публічний сайт і кабінет клієнта: **English, Español, Українська**. Кабінет модератора й адміна: лише **EN і UK**.
- Адреси: англійська без префікса (`/products`), `/es/products`, `/uk/products`. Усередині Next.js це `app/[locale]/...`; `next.config.ts` (`LOCALIZED_ROOTS`) перепише неприфіксовані адреси на `/en/...`. **Новий верхній розділ сайту треба додати в `LOCALIZED_ROOTS`.**
- Словники: `frontend/src/shared/i18n/messages/*.ts`. `defineTrilingual(en, es, uk)` (публічне й клієнтське) і `defineMessages(en, uk)` (адмінка); тип вимагає однакових ключів у всіх мовах.
- SEO: canonical і hreflang на кожну мову, `x-default` на англійську; сторінка мови без перекладу має `noindex` і не потрапляє в hreflang та sitemap.

## Продукти

- `Product.translations` (`{ es: {...}, uk: {...} }`) — частковий переклад; порожні поля показуються англійською. Переклад «живий», коли заповнені короткий опис і опис.
- Публічне API: `GET /api/products/catalog?lang=es`, `GET /api/products/:slug?lang=uk` повертають `availableLocales`.
- Адмін-форма продукту має вкладки EN/ES/UK.
- `npm run products:import` дописує переклади з `prisma/seed/catalog.json` наявним продуктам, у яких їх ще немає (інше не чіпає).
- Stripe Checkout отримує мову покупця (`ES` → `es`, `UK` → `auto`, бо Stripe не має української) і повертає на `/es/success`, `/uk/success`.

## Кабінет клієнта `/account`

- Підписки (статус: діє / скасована з оплаченим періодом / завершена), збережені продукти, профіль і мова.
- `User.locale` береться з мови сайту при реєстрації, змінюється в кабінеті й **використовується для листів**.
- API: `GET/PATCH /api/account`, `GET /api/account/library?lang=`, `GET /api/account/saved?lang=`.
- `notification_service`: усі листи приймають `locale` (`en|es|uk`, за замовчуванням `en`). Бекенд має передавати `user.locale` кожного разу, коли викликає сервіс сповіщень.
  Зараз обробник `invoice.payment_failed` у `billing.service.ts` це заглушка з вшитою адресою: коли її буде замінено на справжню (за Stripe-клієнтом знайти користувача), додайте `locale: user.locale`.

## Блог

### Контент

- Статті: `Article` + `ArticleTranslation` (EN обовʼязкова, ES/UK за бажанням). Кожна мова має **власний slug**, заголовок, анонс, SEO-поля й набір блоків.
- Мова з’являється на сайті, коли в неї є заголовок, slug, анонс і хоча б один блок (`isReady`).
- Блоки: текст (`**жирний**`, `*курсив*`, `[посилання](url)`, списки `- `), заголовок H2/H3 (зі змістом), зображення, відео, цитата, CTA-кнопка, картка продукту.
- Відео: YouTube, Vimeo, TikTok, Facebook, X (лише https). Адреса iframe будується з ідентифікатора, а не береться з введеної адміном; перед кліком нічого стороннього не завантажується.
- Теги й рубрики мають назви в трьох мовах (EN обовʼязкова). «Читайте також» — за спільними тегами, решта найновішими.
- Статуси: чернетка, опублікована, архівна. Майбутня `publishedAt` = планування (стаття зʼявиться сама; кеш сторінок живе до 5 хв).
- Прев'ю: секретне посилання `/blog/preview/<token>` (без кешу, `noindex`); новий токен скасовує старий.

### Адмінка

`/admin/blog` (лише admin): список із фільтрами, редактор із вкладками мов, блок-редактор (вгору/вниз, двокрокове видалення), завантаження й бібліотека зображень, теги й рубрики, SEO-поля, посилання прев'ю.

### Зображення (S3)

Завантаження йде через бекенд (`POST /api/media`, тіло = файл), тип перевіряється за вмістом (JPEG/PNG/WebP/GIF, до 8 МБ і 8000 px). Сховище будь-яке S3-сумісне, налаштовується змінними бекенду:

| Змінна | Призначення |
| --- | --- |
| `S3_BUCKET`, `S3_ACCESS_KEY_ID`, `S3_SECRET_ACCESS_KEY` | обовʼязкові; без них завантаження дає 503 |
| `S3_ENDPOINT` | для не-AWS (R2, MinIO, Spaces) |
| `S3_REGION` | за замовчуванням `auto`/`us-east-1` |
| `S3_PUBLIC_URL` | публічна адреса файлів (CDN або bucket), без `/` в кінці |

Локально `docker compose -f docker-compose.local.yml --profile storage up -d` піднімає MinIO (образи з quay.io, у звичайному `up` його немає) (консоль на `http://localhost:9001`, `xik` / `xik-minio-secret`) і створює відкритий bucket `xik-media`. У продакшні bucket має бути доступний для читання публічно (або через CDN).

### SEO блогу

`BlogPosting` + `BreadcrumbList`, hreflang по слагах кожної мови, OG-картка (обкладинка або згенерована; для української без обкладинки — загальна, бо шрифт OG-карток без кирилиці), `keywords`, RSS на кожну мову (`/blog/rss.xml`, `/es/blog/rss.xml`, `/uk/blog/rss.xml`), статті в sitemap, кнопки шерингу без сторонніх скриптів, час читання.

### Відкладене

Перейменування й видалення тегів/рубрик є в API, але ще без екрана; завантажені зображення не видаляються зі сховища.
